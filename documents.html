📋 How the Template System Works

  1. Write your legal draft in any text editor or Word
  2. Mark all fillable fields with {{FIELD_NAME}}
  3. Save as .txt or .docx
  4. Upload below — the system auto-reads it
  5. It auto-detects the document type (Bhada Karar, POA, etc.)
  6. It builds a smart form with correct input types per field
  7. Fill the form, preview, then export to Word or Print!

⚡ Smart Auto-Detection

• Detects document type (Rent Agreement, Sale Deed, etc.)
• Assigns correct input type (date, number, address, etc.)
• Marks required vs optional fields
• Supports Gujarati text in templates
